# Contributing

Thanks for your interest in improving this profile repository!

## How to contribute

1. Open an issue describing the change or improvement you would like to make.
2. Fork the repository and create a focused branch for your change.
3. Keep changes small, clear, and relevant to the profile or its documentation.
4. Preview Markdown changes before submitting them.
5. Open a pull request explaining what changed and why.

## Pull request checklist

- [ ] The change is relevant to this repository.
- [ ] Markdown formatting is readable.
- [ ] Links and image URLs are valid.
- [ ] No secrets, API keys, or personal information have been added.

Thank you for helping make this profile repository clearer and more useful.
